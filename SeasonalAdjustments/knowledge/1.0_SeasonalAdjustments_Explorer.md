# 1.0 Seasonal Adjustments Explorer — Visual Guide

## Purpose

A "graphic novel" that teaches TIPS seasonality visually: a reader who knows
nothing about seasonal effects pages through annotated, full-screen charts and
ends up understanding (a) why the settlement-date-vs-maturity-month/day gap
matters and (b) why the yield effect is strong for short maturities and fades
for long ones. It is a visual presentation of Canty (2009).

Design language: one hero visual per page, minimal text, annotations drawn ON
the chart (curved arrows, dashed rings, short bold notes) instead of legends
or paragraph blocks. Interactive pages share one control bar (settlement
slider, maturity-month buttons, years buttons, presets) that follows the
reader across pages, so state set on one page carries to the next.

## Book structure (5 chapters, 12 pages)

Navigation: TOC drawer (chapter → page, jump anywhere), Prev/Next pager,
clickable dots, arrow keys. The stage, TOC, and dots are all generated from
one `PAGES` registry in `index.html` — adding a page means adding one registry
entry plus its `drawPn()` renderer.

| # | Chapter | Page | Shows |
|---|---------|------|-------|
| 1 | Inflation Has Seasons | Prices Have Seasons | Avg MoM CPI-U NSA by calendar month (bars + per-year dots) vs the SA line; spring surge / year-end markdowns annotated |
| 2 | | Every Year, the Same Wave | ~7 years of the daily SA Factor; every peak/trough ringed — periodicity = predictability |
| 3 | | One Year, Up Close | One-year daily S curve; peak/trough values; the four TIPS maturity months on the wave |
| 4 | TIPS Ride the Index | A TIPS Is a Stream of Payments | Cash-flow anatomy: tiny coupons, one huge final payment (~94% of value); price = discounted sum |
| 5 | | Every Payment Rides the Index | Index path (trend + exaggerated seasonal ripple) with payment dots landing on the same calendar day each year |
| 6 | The Seasonal Gap | You Buy on One Day of the Wave | Interactive: settle dot vs maturity dot on the one-year wave; the gap bracket quantified |
| 7 | | The Gap Repeats — and Never Cancels | Multi-year timeline: same gap every year, bar thickness ∝ PV, fat final bar = principal |
| 8 | | The Anniversary Trick | Preset buttons: anniversary (gap = 0, no adjustment) vs worst point (max gap, ringed) |
| 9 | Price & Yield | The Fix: One Multiplication | Canty's approximation as a visual equation: quoted price × S(settle)/S(maturity) = SA price, wave dots feeding the ratio |
| 10 | | Same Gap, Any Maturity | Small multiples 1y/2y/3y/5y: identical final gap, identical price multiplier |
| 11 | | …But Yield Spreads It Over Years | SA yield impact (bp) by years-to-maturity: fixed price nudge ÷ duration → shrinking bars |

Pages 10 and 11 are the culmination the book builds toward: the price
adjustment is maturity-independent (page 10) but the yield impact shrinks
with duration (page 11).

## Architecture

No build step; ES modules served statically.

| Module | Role |
|--------|------|
| `index.html` | Shell: CSS, topbar/TOC/pager chrome, `PAGES` registry, shared control bar, navigation + init. No chart math. |
| `src/sa-data.js` | Data layer: R2 fetch (5-yr-avg daily S + ~10y series), `Sat()`, `state` (settleDoy/matIdx/yearsToMat), `defaultSettleDoy()` (T+1 via shared settlement.js), illustrative-bond `cashFlowSchedule()` + `modifiedDuration()` |
| `src/sa-annotate.js` | Annotation layer: `note()`, `arrow()`, `callout()`, `ring()`, `vBracket()`, `pill()` — SVG-string helpers + shared palette |
| `src/sa-pages-cpi.js` | `drawP1()`–`drawP5()` (chapters 1–2) |
| `src/sa-pages-gap.js` | `drawP6()`–`drawP12()` (chapters 3–5), shared `timelineSVG()`, `playgroundReadout()` |

### Interactive state

`state = { settleDoy, matIdx, yearsToMat }` lives in `sa-data.js`. Controls
mutate it and call `redraw()`, which re-renders only the current page.
Defaults at init:

- `settleDoy` — the **real** next bond trading day after today (T+1, skipping
  weekends and SIFMA holidays; holiday fetch optional, 3s timeout).
- `matIdx` — the TIPS maturity month with the **largest seasonal gap** from
  that settlement date, so the story pages land on a visible effect rather
  than the near-anniversary null case (which otherwise occurs whenever today
  is close to mid-January/April/July/October).

### Illustrative bond

Annual coupons (Canty's Eq. 1–14 base case: every payment falls on the
maturity month/day, so one S value covers all payments). Coupon 1.25% ≈
average across outstanding TIPS (TipsRef.csv, 2026-07-11); yields from a
FedInvest real-curve snapshot (2026-07-10) interpolated by years-to-maturity
(1y–10y). Simplified day counts — relative weights, not a trade ticket; real
semiannual/Actual-Actual math lives in `shared/src/bond-math.js` (the local
annual-compounding `modifiedDuration()` is intentionally consistent with the
annual-coupon simplification, not a duplicate of `calculateMDuration`).

### Key visual encodings

- **Gap bars** (pages 7/8/10/12): vertical bar from the S(settle) line to the
  wave at each payment date; **thickness linear in that payment's PV**
  (`1.2 + 22·pv/maxPv`) — thin coupons, fat principal.
- **Yield impact** (pages 11/12): `Δy ≈ (1 − S_settle/S_mat) / ModDur`, in bp.
  Page 11 shows the near-anniversary state as stub bars + a "no gap" note
  (threshold: |1y impact| < 3 bp) instead of normalizing noise to full height.
- **Page 5 ripple** is exaggerated 4× and labeled as such; its y-scale is
  computed from the exaggerated path so the ripple never clips.

## Data source & fallback

Chapter 1 (pages 1–2) needs the raw ~10y series and has **no offline
fallback** (those pages show a "data unavailable" note). Everything from
page 3 on uses the 365-day 5-yr-avg S array, which falls back to built-in
monthly anchors interpolated to daily. The footer line reports which source
is live.

## Testing

Playwright headless against `npx serve .`; local CORS blocks the live R2
fetch, so tests intercept `**/RefCpiNsaSa.csv` and `**/BondHolidaysSifma.csv`
with `page.route()` and serve real curl-fetched copies. Checks: all 12 pages
render (svg innerHTML non-empty), crumb/pager/TOC navigation, preset buttons,
zero console/page errors.
